# Simple Calculator

A minimal command-line calculator built in Python.

## Operations

- `add a b`
- `subtract a b`
- `multiply a b`
- `divide a b`
- `percentage_change new old`
- `compound_growth start rate periods`

## Usage

```bash
python main.py add 2 3
python main.py compound_growth 1000 0.05 10
```

## Tests

```bash
python -m unittest
```

If pytest is installed, you can also run:

```bash
pytest
```
